# Veksha Admin

Небольшая внутренняя панель управления монетизацией:

- точная статистика AI-запросов и токенов по пользователям, функциям и дням;
- диагностическая SQL-консоль PostgreSQL только для чтения;
- цены платных функций в Telegram Stars;
- промокоды на все или выбранные функции;
- история выдачи и счётчики использований промокодов.

## Локальный запуск

```bash
pnpm install
VITE_BACKEND_URL=http://127.0.0.1:8000 pnpm run dev
```

Для входа используется значение backend-переменной `ADMIN_API_SECRET`. Секрет
не собирается в JavaScript bundle и хранится только в `sessionStorage` вкладки.
Для SQL-консоли backend также должен иметь отдельный `ADMIN_DATABASE_SECRET`,
отличающийся от основного секрета. Он вводится в форме консоли, не сохраняется и
не передаёт в браузер `DATABASE_URL`. Запросы ограничены 200 строками, 1 МБ
вывода и тремя секундами, выполняются в транзакции `READ ONLY` и записываются
в аудит.

## Railway

Создайте сервис из каталога `/veksha-admin`, укажите `veksha-admin/railway.toml`
и build-переменную `VITE_BACKEND_URL=https://<backend-domain>`. Домен админки
необходимо добавить в backend-переменную `CORS_ALLOW_ORIGINS`.

Панель является внутренним инструментом с shared-secret авторизацией. Перед
предоставлением доступа нескольким сотрудникам её следует перевести на SSO с
индивидуальными учётными записями и журналом действий.
